# Journal App

A modern and intuitive iOS journaling app designed to capture your daily thoughts and memories with a sleek dark-mode interface and smart organization features.

## Main features
* **Journal Management:** Easily create, view, and delete journal entries.
* **Smart Search & Sort:** Instantly search through entries or sort them by Entry Date and Bookmarks.
* **Quick Bookmarking:** Mark important moments for fast access.
* **Custom Discard Alert:** A secure glassmorphism confirmation pop-up that prevents accidental loss of edits.

## Tech Stack & Preview
* **Framework:** SwiftUI
* **Design:** iOS Human Interface Guidelines (Dark Mode & Liquid Glass)
* **Architecture:** MVVM
